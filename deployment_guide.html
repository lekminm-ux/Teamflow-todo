คู่มือติดตั้งแอปพลิเคชันขึ้น Cloudflare Pages + D1 SQL Database

ระบบดึงข้อมูลและอัปโหลดอัตโนมัติผ่าน GitHub

ความคืบหน้าการติดตั้ง 0%
1
อัปโหลดไฟล์เว็บขึ้น GitHub

นำไฟล์โค้ดในคอมพิวเตอร์ของคุณขึ้นไปสร้าง Repository ในบัญชี GitHub เพื่อนำไปเป็นตัวต้นฉบับดึงข้อมูล:

  1. เข้าเว็บ GitHub.com และกดปุ่ม New Repository เพื่อสร้างใหม่
  2. ตั้งชื่อโครงการเป็นภาษาอังกฤษ เช่น teamflow-todo จากนั้นกดสร้าง
  3. ในหน้าถัดไป ให้คลิกคำว่า "uploading an existing file"
  4. ลากไฟล์ในคอมพิวเตอร์ทั้งหมด ได้แก่ index.html, style.css, app.js, schema.sql, wrangler.toml และ โฟลเดอร์ functions ไปวางในเบราว์เซอร์
  5. เมื่อโหลดเสร็จ ให้เลื่อนไปกดปุ่มสีเขียว "Commit changes"
2
สร้างฐานข้อมูลคลาวด์ D1 SQL

สร้างฐานข้อมูล SQL บน Cloudflare เพื่อใช้เก็บบันทึกงบประมาณและข้อมูลชื่องานร่วมกันภายในทีม:

  1. เข้าสู่ระบบที่เว็บ dash.cloudflare.com
  2. เมนูด้านซ้ายมือ คลิกหัวข้อ "Storage & databases" แล้วกดเลือกเมนูย่อย "D1 SQLite Database"
  3. คลิกปุ่มสีน้ำเงิน "Create database"
  4. พิมพ์ชื่องานในช่อง Name ว่า: teamflow-db จากนั้นกดปุ่ม "Create"
3
ตั้งค่าโครงสร้างฐานข้อมูล (Console SQL)

คัดลอกคำสั่งโครงสร้างตารางไปรันในคอนโซลของฐานข้อมูล:

  1. ในหน้าแดชบอร์ด D1 ที่เพิ่งสร้าง ให้เลือกแท็บที่สองหัวข้อ "Console"
  2. คัดลอกโค้ด SQL ด้านล่างนี้ทั้งหมดไปวางลงในช่องป้อนคำสั่ง:
CREATE TABLE IF NOT EXISTS tasks (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,
    createdDate TEXT NOT NULL,
    deadline TEXT NOT NULL,
    assignee TEXT NOT NULL,
    budget REAL DEFAULT 0,
    status TEXT NOT NULL,
    correctiveAction TEXT DEFAULT '',
    remark TEXT DEFAULT ''
);

CREATE INDEX IF NOT EXISTS idx_tasks_assignee ON tasks(assignee);
CREATE INDEX IF NOT EXISTS idx_tasks_status ON tasks(status);
  1. คลิกปุ่มสีน้ำเงิน "Execute" ด้านขวา จะต้องมีข้อความสีเขียวตอบรับความสำเร็จขึ้นมา
4
ติดตั้งและสร้าง Cloudflare Pages

ดึงไฟล์หน้าเว็บจาก GitHub มาจัดวางในโหมด Pages ของ Cloudflare:

  1. เมนูด้านซ้ายมือสุดของ Cloudflare คลิกที่เมนู "Compute" จากนั้นเลือกย่อย "Workers & Pages"
  2. คลิกปุ่มสีน้ำเงิน "Create application"
  3. จุดสำคัญ: เลื่อนลงด้านล่างสุดของตัวเลือกแล้วคลิกที่คำว่า Get started (ในหัวข้อ Looking to deploy Pages?)
  4. คลิกเลือกหัวข้อแรก "Import an existing Git repository" (ปุ่ม Get started)
  5. คลิกปุ่ม "Connect GitHub" และกดปุ่มสีเขียวอนุญาตสิทธิ์เข้าถึงบัญชี
  6. เลือกชื่อโปรเจกต์ teamflow-todo จากนั้นกดปุ่ม "Begin setup"
  7. ช่อง Project name ให้เขียนตัวพิมพ์เล็กทั้งหมด เช่น teamflow-todo และให้กดปุ่มสีน้ำเงิน "Save and Deploy" ได้ทันที
5
เชื่อมฐานข้อมูล D1 เข้ากับแอป และ Deploy ซ้ำ

ผูกข้อมูลสองส่วนเข้าหากันเพื่อให้ระบบคุยกับฐานข้อมูลได้:

  1. เมื่อหน้าจอบอกความสำเร็จในการ Deploy ครั้งแรก ให้กดปุ่ม "Continue to project"
  2. คลิกแท็บเมนูหัวข้อ "Settings" ด้านบน จากนั้นเลือกเมนูย่อย "Bindings" ทางแถบซ้ายมือ
  3. ในหัวข้อ Bindings ตรงกลางจอ ให้คลิกปุ่ม "+ Add" แล้วเลือกคลิกคำว่า "D1 database"
  4. กรอกฟอร์มการเชื่อมต่อดังนี้:
    • ช่อง Variable name: พิมพ์ตัวใหญ่คำว่า `DB` เท่านั้น
    • ช่อง D1 database: เลือกชื่อฐานข้อมูลคลาวด์ `teamflow-db`
  5. คลิกปุ่ม "Save" เพื่อบันทึกข้อมูล
  6. ขั้นตอนสุดท้าย: ไปแท็บเมนู "Deployments" ด้านบนขวาสุด คลิกที่ปุ่ม "Manage deployment" และกดคำสั่ง "Retry deployment" เพื่อสั่งให้เว็บเชื่อมต่อและทำงานร่วมกับฐานข้อมูลคลาวด์สมบูรณ์ 100%!
